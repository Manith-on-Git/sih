# Test Data & Package Image Samples

## Purpose
This directory stores test images of packaged commodities across various categories (food items, personal care, electronics, imported goods) for testing label detection, OCR, and compliance checking.

## Recommended Test Image Categories
1. **Clear Flat Labels**: Box packaging, cereal boxes, tea cartons with flat, high-contrast labels.
2. **Cylindrical / Curved Containers**: Bottles, cans, spray containers requiring perspective and curved surface handling.
3. **Flexible Pouches**: Chips packets, spice pouches with wrinkles and variable lighting.
4. **Multi-panel Packaging**: Packages where mandatory declarations are split between Principal Display Panel (PDP) and Information Panel.
5. **Non-compliant Samples**: Real or synthetic packaging samples intentionally omitting one or more declarations (e.g., missing consumer care contact, missing manufacturing month/year) for rule verification.
